# Contributing

Thanks for helping out.

1. Open an issue first for anything bigger than a small fix.
2. Make your change on a branch, one change per pull request. Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/).
3. Run `just setup` once, then `just check` before opening the pull request.
4. Add a line under `Unreleased` in CHANGELOG.md for user-visible changes.

Developer documentation (architecture, evaluation, installers, ADRs) is in [`docs/dev/`](docs/dev/README.md).

By taking part you agree to the [Code of Conduct](https://github.com/thetaplex/.github/blob/main/CODE_OF_CONDUCT.md).
