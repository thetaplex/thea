# Set Project Instructions and Pin Knowledge Files

You can attach instructions and reference files to any project so that Thea includes them in the system prompt for every chat in that project.

## Add Project Instructions

1. Select your project under **Projects** in the left sidebar.
2. Click the **Context** button next to the active project name.
3. Type your rules or conventions in **Project System Instructions**.
4. Select the default persona for this project in **Default Project Persona**.
5. Click **Save**.

## Pin Knowledge Files

1. Open the right pane and click the **Files** tab.
2. Hover over the file you want to pin.
3. Click the pin icon (`Pin file to Project Knowledge context`).
4. Click the pin icon a second time to unpin the file. You can also remove it in **Context**.
