# Create a Custom Persona

A persona sets the system instructions, starter prompts, allowed skills, and allowed `MCP` servers for the chats in a project. A chat without a project has no persona.

1. In the left sidebar, click **New** next to **Projects**. In the dialog, find **Assistant Persona** and click the **New persona** button.
2. Type a name in **Persona Name** and a short summary in **Tagline**.
3. Write the behavior rules in **System Instructions**.
4. Add your starter prompts in **Starter Prompts**, with 1 prompt on each line.
5. Select specific skills under **Linked Skills**, or leave all boxes unchecked to allow all of the active skills.
6. Select specific servers under **Linked MCP Servers**, or leave all boxes unchecked to allow all of the active `MCP` servers.
7. Click **Create Persona**. The project dialog selects the new persona.
